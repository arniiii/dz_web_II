# Форматы строк курсора

## Подготовка

Выполните `uv sync`, затем запускайте тесты командой `uv run pytest` или `make test`. `init.sql` повторяемо пересоздаёт `customers` и `orders`.

## src/solution.py

Допишите `get_order_sum(conn, month)`. Она должна вернуть общую сумму заказов каждого покупателя за заданный месяц в виде одной строки, по одному покупателю на строку.

Для тестовых данных при `month = 2` ожидается:

```text
Покупатель John Smith совершил покупок на сумму 240
Покупатель Michael Brown совершил покупок на сумму 800
```

```python
import psycopg
from psycopg.rows import dict_row

conn = psycopg.connect("...", row_factory=dict_row)
```

## Подсказки

- В Psycopg 3 словари строк задаются через `row_factory=dict_row` у соединения или курсора.
- Используйте плейсхолдер `%s` для месяца.
- Сгруппируйте результаты по покупателю и суммируйте `total_amount` в SQL.
- Курсор открывайте контекстным менеджером и не закрывайте переданное соединение.
