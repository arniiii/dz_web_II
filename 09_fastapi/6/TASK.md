# Обработчик запросов с параметрами заголовка

## src/main.py

Доработайте FastAPI-приложение. Добавьте в него обработчик:

- GET `/validate-api-key` — должен принимать пользовательский HTTP-заголовок `X-API-Key`, который передает клиент.

Если ключ валиден, сервер должен вернуть сообщение о разрешении доступа. Не возвращайте ключ в теле ответа. Если формат ключа неверен, верните ошибку с кодом 400 и сообщением "Invalid API Key format".

Валидный API-ключ должен быть строкой длиной 32 символа, состоящей из букв и цифр.
