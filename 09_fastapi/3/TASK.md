# Обработчик запросов с параметром

## src/main.py

Доработайте FastAPI-приложение. Добавьте в него обработчик:

- GET `/square` — должен принимать параметр запроса `number` и возвращать квадрат переданного числа. 

Ответ должен быть в формате JSON:

```json
{"number": {number}, "square": {square}}
```

Если параметр `number` отсутствует, возвращайте JSON-ответ по умолчанию:

```json
{"number": null, "square": null}
```
