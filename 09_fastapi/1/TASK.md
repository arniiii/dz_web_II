# Обработчик запросов FastAPI

## src/main.py

Доработайте FastAPI-приложение. Добавьте в него обработчик:

- GET `/items` — должен возвращать список предметов в формате JSON. 

Данные:

```json
items = [
    {"id": 1, "name": "Item 1"},
    {"id": 2, "name": "Item 2"},
    {"id": 3, "name": "Item 3"}
]
```

Используйте объект FastAPI для создания приложения и декоратор пути для определения обработчика запроса.
