# Частичное обновление и модели ответов

## src/main.py

Расширьте приложение для управления товарами. Данные хранятся во временном списке.

- POST `/products` принимает модель `ProductCreate` с полями `name`, `price` и вложенными `specifications`. Цена должна быть больше нуля. Возвращайте созданный товар с кодом `201` и моделью ответа без лишних полей.
- GET `/products` принимает необязательный параметр `min_price` (не меньше нуля) и возвращает только товары, цена которых не ниже этого значения. Используйте `response_model` для возврата только `id`, `name` и `price`.
- PATCH `/products/{product_id}` принимает модель `ProductUpdate`. Все её поля необязательны. Обновляйте только поля, которые передал клиент; не затирайте остальные значения `null` или значениями по умолчанию.
- Если товара с указанным идентификатором нет, возвращайте `404` с сообщением `Product not found`.

Модели:

- `ProductSpecifications`: `size`, `color`, `material`;
- `ProductCreate`: входные данные при создании;
- `ProductUpdate`: необязательные поля для PATCH;
- `ProductResponse`: `id`, `name`, `price`;
- `ProductDetailResponse`: `id`, `name`, `price`, `specifications`.
