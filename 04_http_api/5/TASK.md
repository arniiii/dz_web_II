# HTTPie

В этом задании вам нужно написать запрос на получение данных о курсах в формате JSON с помощью HTTPie.

## solution

- Используя _HTTPie_, выполните запрос к _localhost_ на порт 8080 по пути _/courses_.
- В заголовке запроса сообщите серверу, что ожидаете ответа в формате JSON.
- Если запрос успешный, то в терминале упражнения вы увидите список курсов, который вернул сервер.
- Получившуюся команду запишите в файл _solution_.

## Подсказки

- Для указания заголовка в HTTPie используйте синтаксис `Accept:application/json` (без флага `-H`).
- Чтобы в stdout попало только тело ответа (без заголовков), добавьте флаг `-b`.
- Добавьте `--ignore-stdin`, иначе HTTPie может ждать данные из stdin и отправить пустое тело.
