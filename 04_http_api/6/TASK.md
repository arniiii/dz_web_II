# Аутентификация (API Key)

В этом задании нужно получить доступ к защищённому ресурсу с помощью API-ключа.

## solution

- Используя _curl_, выполните запрос к _localhost_ на порт 8080 по пути _/private_.
- Передайте в заголовке запроса API-ключ: `X-API-Key` со значением `1234asdf`.
- Если запрос успешный, сервер вернёт секретные данные.
- Получившуюся команду запишите в файл _solution_.

## Подсказки

- Для указания заголовка используйте флаг `-H`.
