# Авторизация (Bearer)

В этом задании нужно получить доступ к защищённому ресурсу с помощью Bearer-токена.

Сначала получите токен — выполните POST-запрос к _localhost:8080/login_ с телом:

```json
{"username":"admin","password":"admin"}
```

Не забудьте указать заголовок `Content-Type: application/json`. В ответе сервер вернёт объект с полем `token`.

## solution

- Используя _curl_, выполните GET-запрос к _localhost_ на порт 8080 по пути _/private_.
- Передайте в заголовке `Authorization` полученный токен в формате Bearer: `Authorization: Bearer <token>`.
- Если запрос успешный, сервер вернёт секретные данные.
- Получившуюся команду (только GET к `/private`) запишите в файл _solution_.

## Подсказки

- Для указания заголовка используйте флаг `-H`.
- Формат заголовка: `Authorization: Bearer <token>`.
